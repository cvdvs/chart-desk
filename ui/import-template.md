# Chart Desk — import list

Fill in one row per person, then import this file: **sidebar → the ⤒ Import button → paste it in → Preview → Import.**
Everything computes on the Mac; nothing leaves the device.

## How to fill it in

Keep the header row and the `|---|` line. Delete the two example rows and add your own.

- **Name** — required.
- **Date** — required. Format `YYYY-MM-DD` (e.g. `1990-06-15`). Year, then month, then day.
- **Time** — `HH:MM` on a 24-hour clock (e.g. `14:30`, or `09:05`). **Leave it blank if you don't know it** — the chart is cast at noon and clearly flagged, and the hour-sensitive parts (ascendant, houses) are withheld rather than guessed.
- **Place** — a city as `City, Country` (e.g. `Bucharest, Romania`). The app looks up the coordinates and timezone for you. If a city name is ambiguous, add the region: `Berlin, Vermont, United States`. If you already have exact coordinates, put them in this column instead as `lat, lon, timezone` — e.g. `44.43, 26.11, Europe/Bucharest`.
- **Category** — `Personal Circle`, `Clients`, `Research`, `Other`, or the name of any section you've made. Leave blank to use the default you pick in the Import window.
- **Tags** — comma-separated, e.g. `scraped, historical`. Optional.
- **Notes** — anything you want to remember. Optional.

You can leave any optional column blank, but keep the `|` bars so the columns line up.
